# Welcome to Camemark

Camemark is an enchanting e-commerce platform for the 10 economic blocs of Cameroon.

## Documentation & Manuals
- [Technical Documentation](documentation.md) - Deep dive into the architecture and tech stack.
- [User Manual](user_manual.md) - Guide for buyers, sellers, and farmers.
- [Admin Manual](admin_manual.md) - Guide for platform administrators.

## Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`
